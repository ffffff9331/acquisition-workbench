# 获客工作台

> 面向中小企业和门店的模块化客户增长工作台。

- **当前版本：** `v0.20.0`
- **项目状态：** 内部开发 / Windows 测试版
- **仓库权限：** Private，不对外公开

## 项目简介

获客工作台不是某个行业的一套固定表单，也不是自动登录平台、批量发布内容的营销机器人。

它由一个跨行业通用的客户增长 Core、多个渠道基础能力和可按需安装的行业内容包组成。交付时可以根据客户的行业、获客渠道和实际需求组合不同模块，不需要每次从零开发一套软件。

```text
通用 Core
  + 渠道基础能力
  + 行业内容包
  + 行业打法包
  = 客户专属获客工作台
```

产品重点不是“生成一篇内容就结束”，而是把真实来源、内容生产、人工执行、线索承接、成交结果和持续复盘连接成一条可追踪的工作流。

## 产品结构

### 通用 Core

所有行业共用六个一级工作区：

```text
工作台 / 获客 / 线索 / 意向客户 / 客户 / 复盘
```

Core 负责保存客户增长过程中的通用对象、状态和结果，包括：

- 获客任务与来源编号
- 线索登记、筛选和负责人
- 意向客户跟进与下一步任务
- 成交、丢单和客户沉淀
- 回访、复购与转介绍提醒
- 渠道来源与业务结果复盘

### 渠道基础能力

渠道作为独立能力按需启用，当前包括：

- 抖音
- 小红书
- 微信
- B站
- 线下活动
- 转介绍合作

不同渠道共享客户、来源、线索和复盘底座，但分别保留适合平台的内容结构、素材要求、检查项和执行记录。

工作台不代替用户登录平台，不保存平台 Cookie，也不自动发布、自动私信或自动群发。最终发布和客户沟通由用户人工完成，以降低账号风险并保留经营判断。

### 行业内容包

行业内容包为渠道能力补充行业知识、客户问题、产品场景、证明素材、表达边界和内容模板。

当前内置第一份可测试内容包：

```text
家装家居 > 卫浴门店
```

后续内容包可以独立制作、签名、下载和安装，不改变通用 Core。客户可以只启用需要的渠道和内容包。

## 当前能力

### 联网选题研究

- 按全网或指定平台检索公开网页
- 保存真实来源，而不是只使用内置标题库
- 从客户原话、比较决策、避坑投诉、案例结果和本地需求中发现机会
- 要求至少两条真实来源后再形成获客机会
- 保存目标客户、购买阶段、需求信号、证据、承接动作和风险提示

### 内容生产

- 建立跨渠道共用的内容简报
- 为不同渠道生成独立内容版本
- 保存标题、开头、正文或脚本、客户下一步、封面文案和素材安排
- AI 覆盖草稿前自动保留历史版本
- 支持本地规则检查、AI 深度评审和人工通读
- 生成候选优化稿，但不自动覆盖当前草稿
- 完成证据、素材和事实核对后才能锁定最终稿

### 执行与归因

- 将最终稿关联到具体渠道任务
- 为执行中的任务生成来源编号
- 回收曝光或到场、咨询、有效线索和成交结果
- 记录继续投入、调整后再试或停止投入
- 根据真实执行结果提出学习建议
- 只有人工采用的规则才会影响后续同渠道生成

### AI 服务

支持两种配置方式：

1. 官方 AI 服务：客户使用工作台编号和授权码，通过官方网关消费预付积分。
2. 自有 AI 服务：客户配置第三方 OpenAI 兼容地址、模型和 API Key，费用直接向第三方支付。

第三方 API Key 和官方授权码由 Electron 主进程调用系统安全存储保存，不写入客户业务数据或导出文件。默认官方网关地址为空，未部署服务时不会显示虚假余额、套餐或充值结果。

## 技术栈

- Electron
- React
- TypeScript
- Vite
- electron-builder
- NSIS Windows 安装器

应用以 Windows 10 / Windows 11 x64 为主要交付环境。业务数据默认保存在客户本机，目前不依赖持续在线的业务服务器；联网搜索、AI 生成、积分和支付能力需要对应服务端支持。

## 本地开发

建议使用 Node.js 20 LTS 或更高版本。

```powershell
npm install
npm run dev:desktop
```

仅启动浏览器开发页面：

```powershell
npm run dev
```

## 验证与构建

运行 AI 服务契约测试：

```powershell
npm run test:ai-service
```

运行 TypeScript 和生产构建：

```powershell
npm run build
```

生成 Windows x64 安装包：

```powershell
npm run dist:win
```

构建结果生成在本地 `release` 目录，该目录不提交到 Git。正式测试安装包通过 GitHub Releases 单独发布。

## 安全边界

本项目明确不提供以下能力：

- 自动登录第三方内容平台
- 保存或共享平台账号、密码和 Cookie
- 自动发布、批量私信或批量群发
- 未经授权抓取联系人或客户资料
- 绕过平台风控、验证码或访问限制
- 用 AI 评分承诺流量、咨询量或成交率

所有模型输出都应经过事实核对和人工确认。行业内容包不得包含无法证明的效果承诺、虚假案例或违规平台操作规则。
